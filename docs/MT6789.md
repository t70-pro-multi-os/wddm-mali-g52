# The mt6789 branch: Mali-G57 MC2 on the Teclast T70 Pro

This branch ports gahingwoo's Mali-G52 WDDM driver to the Mali-G57 MC2 in the
MediaTek MT6789 (Helio G99), on the Teclast T70 Pro running Windows 11 on ARM
from the Mu-Silicium firmware (`Platforms/Teclast/t70proPkg`).

The design is unchanged from upstream: Mesa's Panfrost under the d3d10umd
frontend as the user-mode driver, the libdrm shim in `win32-compat/`, `malikm`
for bring-up and `maliwddm` for the desktop. The Pixel 6 branch
(isaacjamessss/wddm-mali-g52, `gs101`) showed the same stack on the Mali-G78,
a Valhall job-manager GPU like the G57; its two 16 MiB shader stack patches
are carried here as `mesa-patches/0076` and `0077`.

## Hardware

From the stock device tree (`mt6789-gpu.dtsi`, `mt6789-power.dtsi`) unless
noted.

| | |
|---|---|
| GPU | Mali-G57 MC2, Valhall v9, job manager. `compatible = "mediatek,mali", "arm,mali-valhall"` |
| GPU_ID | `0x90930010` (tNAx r0p1), read on an MT6789 by ahsanihlwn/mt6789-mali-winarm64. Mesa 26.2 already lists it as `PAN_PROD_ID(9, 0, 3)` "G57" |
| Registers | `0x13000000`, 16 KiB |
| MFG top config | `0x13FBF000`, 4 KiB (`mfg_top_config`, clock gate `CLK_MFGCFG_BG3D`) |
| Interrupts | GIC SPI 396 GPU, 397 MMU, 398 JOB, 399 EVENT, 400 PWR, level high (GSIV 428 to 432) |
| Clocks | `CLK_TOP_MFG_PLL_SEL`, `CLK_TOP_MFG_REF_SEL`, `CLK_TOP_MFGPLL`, `CLK_TOP_MFG_REF` (topckgen `0x10000000`) |
| Power | scpsys domains MFG0 to MFG3 (SPM `0x10006000`); supplies `mt6358_vgpu` and `mt6358_vsram_gpu` |
| Clock and voltage table | 44 points, 1100 MHz at 900 mV down to 390 MHz at 675 mV |
| Stock Linux driver | Arm kbase (`mali_kbase_mt6789.ko`) with `mtk_gpufreq_mt6789.ko` and `ged.ko` |

The panel is driven by MediaTek MMSYS (OVL, RDMA, DSI), not by the GPU. The
firmware leaves a GOP framebuffer behind that OVL scans out.

## Plan

| | Step | Needs the tablet |
|---|---|---|
| T0 | CI builds Mesa (with Valhall) and the drivers on this branch | no |
| T1 | Firmware powers the GPU (MFG0 to MFG3, MFGPLL, BG3D gate, vgpu/vsram) and describes it in ACPI. Written and checked against the stock sources: [MT6789-POWER.md](MT6789-POWER.md) | no to write, yes to prove |
| T2 | `malikm` runs a job on the G57 (GPU_ID, soft reset, MMU, one job, interrupts) | yes |
| T3 | Panfrost draws the first triangle on the G57 through `malikm` | yes |
| T4 | `maliwddm` on MT6789: present by copying into the GOP framebuffer first, then point the OVL layer at the rendered primary | yes |
| T5 | GPU clock and voltage from the stock table | yes |

The Rockchip display code (VOP2, HDMI, hot-plug, backlight) stays for the
upstream boards; MT6789 gets its own scanout and leaves those paths unused.
